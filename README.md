# Moore Fundraising Solutions: Claude Plugins for Nonprofits

Free Claude plugins for nonprofits, from Moore Fundraising Solutions.

## MFS DIY Grant System

A do-it-yourself AI grant system for small and midsized nonprofits. Check your readiness, build your AI policy, theory of change, master grant, and goal budget, then find funders, plan deadlines, draft proposals and budgets, check before submitting, manage awards, and write reports.

[Read more about the MFS DIY Grant System](plugins/mfs-diy-grant-system/README.md)

## Install

You need a paid Claude plan (Pro, Max, Team, or Enterprise).

1. In Claude, open **Customize** in the sidebar, then **Plugins**.
2. Select **Add marketplace** and enter: `amoore-fundraising/mfs-diy-grant-system`
3. Find **MFS DIY Grant System** and select **Install**.
4. In a new chat, type: **Set up my grant system**
