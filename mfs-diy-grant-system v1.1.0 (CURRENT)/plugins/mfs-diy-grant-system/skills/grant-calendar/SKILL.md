# Grant Calendar

Keep the organization's grant deadlines in one place and answer "what's due" on request. This skill runs only when asked. Do not set up recurring reports or reminders unless the user asks for them.

Apply organization-profile and grant-guardrails throughout.

## Adding a grant

1. Read the Grant Calendar's columns and status options (see organization-profile).
2. Gather what is known: funder, program, request amount, application type (LOI, full proposal, renewal), deadline, owner, and the funder's guidelines link.
3. Verify the deadline on the funder's own website. If you cannot verify it, leave the date blank and put `[CONFIRM: deadline]` in the notes.
4. Suggest internal dates working back from the deadline, unless the user already set them:
   - Materials gathered: four weeks before
   - First draft done: three weeks before
   - Review done: one week before
   - Final approval: three business days before
5. Show the user what you will add. Add it only after they say yes.
6. Check the Funders list. If the funder is not there, offer to add it.

## Answering "what's due"

1. Read the Grant Calendar and any report dates on it.
2. List items due in the period the user asked about (default: the next 30 days), sorted by date:
   - Funder, what is due (LOI, proposal, report), due date, owner, status
3. Point out anything overdue, anything due within seven days that is not started, and anything with no owner.
4. Keep it short. Offer to start the next step, such as start-grant or draft-grant-report.

## Updating

When the user says something changed (new deadline, new owner, submitted), show the change and update the Grant Calendar only after they say yes. Add a short note on the row saying what changed and why.
