# Grant Tracker: tabs and columns

Create one spreadsheet named "[Organization] Grant Tracker" with these five tabs, in this order. Freeze the header row on each tab. Use dropdowns (data validation) for the columns that list options.

## Tab 1: Grant Calendar

| Column | Notes |
| --- | --- |
| Funder | |
| Grant or program name | |
| Our program | Official program name from the profile |
| Type | Dropdown: LOI, Proposal, Renewal, Report |
| Request amount | Currency |
| Deadline | Date |
| Deadline verified on | Date the deadline was checked on the funder's website |
| Materials gathered by | Date, usually four weeks before the deadline |
| First draft by | Date, usually three weeks before |
| Review by | Date, usually one week before |
| Final approval by | Date, usually three business days before |
| Owner | |
| Status | Dropdown: Researching, Planned, Drafting, In review, Ready to submit, Submitted, Awarded, Declined, Report due, Closed |
| Amount awarded | Currency. Fill in when awarded. |
| Interim report due | Date |
| Final report due | Date |
| Grant folder link | |
| Notes | Short dated notes on what changed and why |

## Tab 4: Program Data

One row per number. This layout works for any number of programs and measures.

| Column | Notes |
| --- | --- |
| Program | Official program name |
| Period | e.g. 2026 Q1 |
| Measure | e.g. Families served, Percent reading at grade level |
| Measure type | Dropdown: Output, Outcome, Service units |
| Value | Number |
| How it was measured | e.g. attendance records, pre and post survey |
| Source | Where the number came from |
| Entered by | |
| Notes | |
