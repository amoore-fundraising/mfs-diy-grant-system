# Draft a Grant Report

Small teams rarely struggle to write a report. They struggle to remember what they promised and to find the numbers. This skill uses the Grant Commitments Sheet and Program Data to solve both.

Apply organization-profile and grant-guardrails throughout.

## Drafting a report

### Step 1: Gather

Ask for, or find in the grant's folder and the grant tracker:

1. The grant's filled-in Grant Commitments Sheet. If there is none, use the proposal and award letter, and suggest filling out a Commitments Sheet afterward with award-and-stewardship.
2. The funder's report questions or form, if there is one
3. Program Data for the grant period, from the grant tracker
4. Anything new from the user: stories with consent, staff changes, challenges

### Step 2: Draft

- Use the organization's Grant Report Template if the profile links one. Otherwise use the template in `templates/grant-report-template.md` in this skill's folder.
- If the funder has its own form, answer each question using the matching section of the template. Otherwise use the template as written.
- Report on every commitment in the Commitments Sheet, including any that fell short, with a short, honest explanation and what the organization is doing about it.
- Use only numbers from the Commitments Sheet, Program Data, or documents the user provides. Give each number its time period. Never estimate; use a placeholder.
- Present outputs first, then outcomes.
- Use only stories and quotes the user confirms were shared with consent.
- Include required acknowledgments, such as how the funder was recognized.
- End with a Sources list showing where each number came from.

### Step 3: Hand back

Save the draft in the grant's folder as "[Funder] [Year] [Interim or Final] Report - Draft", or give it in the chat. List every placeholder and any commitment with no data. Offer to update the grant's row on the Grant Calendar after the user submits it.

## Entering quarterly numbers

When the user wants to enter a quarter's program data:

1. Read the Program Data columns.
2. Ask for each program's numbers for the quarter: outputs, the outcome measures listed, and the service unit count.
3. Show what you will enter. Enter it only after the user says yes.
4. Point out any number that looks very different from the last quarter, so the user can confirm it is correct. Do not change it.
