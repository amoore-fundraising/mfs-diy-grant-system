# Moore Fundraising Solutions: Claude Plugins for Nonprofits

Free Claude plugins for nonprofits, from Moore Fundraising Solutions.

## MFS DIY Grant System

A do-it-yourself AI grant system for small and midsized nonprofits. Start with the documents you already have, then find funders, keep track of deadlines, draft proposals and budgets, check grants before you submit, manage awards, and write reports. Optional help is built in to strengthen your grants over time.

[Read more about the MFS DIY Grant System](plugins/mfs-diy-grant-system/README.md)

## Install

You need a paid Claude plan (Pro, Max, Team, or Enterprise). Nonprofits can get up to 75% off Team and Enterprise plans: [claude.com/solutions/nonprofits](https://claude.com/solutions/nonprofits).

1. In Claude, click **Customize** in the left sidebar. (Use the sidebar, not the chat box.)
2. Click the **Plugins** tab.
3. Click **Add**, then **Add marketplace**.
4. Choose **Add from a repository** and enter: `https://github.com/amoore-fundraising/mfs-diy-grant-system`
5. Find **MFS DIY Grant System** in the list and click **Install**.
6. **Check that it is turned on.** If the plugin shows as disabled, turn it on.
7. Open a **new** chat and type: **Set up my grant system**
