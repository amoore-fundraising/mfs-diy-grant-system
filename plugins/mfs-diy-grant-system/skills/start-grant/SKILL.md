# Start a Grant

Get everything in place before writing begins, so the draft is built on current, complete information.

Apply organization-profile and grant-guardrails throughout.

## Step 1: Confirm the opportunity

Find the grant on the Grant Calendar. If it is not there, offer to add it with grant-calendar.

Using the funder's guidelines and the funder's own website, confirm:

- Deadline (verified on the funder's site, with the date you checked)
- LOI first, full proposal, or renewal
- Request amount or range allowed
- Grant period
- Match or cost-share requirement
- Letters of support required
- Required attachments
- Application questions, with word or character limits
- How it is submitted (portal, email, mail)
- Any eligibility rule the organization might not meet. Flag it; the user decides.

If the user has not shared the guidelines or the questions, ask for them. They are always required.

## Step 2: Check what is on hand

Look in file storage and the Claude Project files (see organization-profile) for:

- Master Grant Narrative and Theory of Change
- Program data for the programs involved (Program Data in the grant tracker)
- Current organizational budget and a project budget, if one exists
- Audit or financial review, 990, IRS determination letter, board list
- Past proposals to this funder or similar funders
- Consented stories that fit this program

Then check how current each one is:

- Program data or financials more than one year old: flag
- Annual report more than one year old: flag, unless it is the most recent
- Strategic plan more than three years old: flag
- Master Grant Narrative not updated in the last six months: suggest update-master-grant first
- No Master Grant Narrative at all: suggest building one with master-grant first. It makes every proposal faster and more accurate. The user can still choose to draft without it.
- Statistics in the needs statement more than three years old: flag

Mark anything missing entirely as missing, not stale.

## Step 3: Give the user a kickoff summary

Keep it to one screen:

1. **The opportunity:** funder, deadline, request, type, submission method
2. **Requirements checklist:** each question and attachment, with limits
3. **Ready:** materials on hand and current
4. **Needs attention:** stale or missing items, and who likely has them
5. **Questions for the user:** only what cannot be found in the files or the grant tracker

Offer to save the summary in the grant's folder and add a note to the grant's row on the Grant Calendar. Do this only after the user says yes.

## Step 4: Next step

When materials are ready, hand off to draft-proposal. If the funder needs a project budget, hand off to grant-budget, which can run before or alongside the draft.
