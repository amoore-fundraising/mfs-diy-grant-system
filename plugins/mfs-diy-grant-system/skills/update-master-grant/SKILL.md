# Update the Master Grant

The Master Grant Narrative is the single source every proposal is built from. When it is current, every grant gets easier. This skill keeps it that way.

Apply organization-profile and grant-guardrails throughout.

## Mode A: Something changed

1. Ask what changed, if the user did not say, and for the source (new annual report, board decision, program data, and so on).
2. Read the current Master Grant Narrative from file storage or the Claude Project files. If there is none, offer to build one with master-grant instead.
3. Find every place the change touches. A new number of people served, for example, may appear in the organization overview, a program section, the Impact and Outcomes section, and the Grant Summary.
4. Show the user each proposed change: section, current text, new text, and source.
5. Make the changes only after the user says yes. If Claude cannot edit the document directly, give the user the updated sections to paste in. Keep a short change note at the end of the document: date, what changed, source.
6. If a program name, outcome, or service area changed, remind the user that their Grant System Profile and the Theory of Change may need the same update. Offer to update the profile document; change it only after the user says yes.

Never change the mission, vision, or values unless the user confirms the board adopted new wording.

## Mode B: Freshness check

Read the Master Grant Narrative and report:

- Statistics more than three years old, with a suggested newer source from the Grant Data Sources folder or a credible public source (open it and confirm the figure before suggesting it)
- Organization numbers from a fiscal year more than one year old
- Current Funders entries with past renewal dates
- Staff or board names that may be out of date
- Missing or out-of-date items in the Important Documents Checklist
- Remaining placeholders

Give the list as a short table: section, issue, suggested fix. Offer to make the fixes the user approves.

Suggest a freshness check every six months, and before a large application.
